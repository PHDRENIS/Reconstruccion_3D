# Ejemplos RealSense D430

Muestras capturadas con Intel RealSense D430 (IR + Depth). Los `.png` están versionados como ejemplo visual.
Los `.raw` originales (~400 KB c/u) se ignoran por `.gitignore` (`docs/ejemplos/*.raw`) — se mantienen localmente pero no se suben a GitHub por bloat.
Ver `data/samples/` para 3 imágenes mínimas usadas por el pipeline.

Metadata CSV asociada (resolución, formato) se versiona.
